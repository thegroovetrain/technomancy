1 · Order & Value

The English Qabalah alphabet

Start at A and take every eleventh letter of the ordinary alphabet, wrapping around. Value is position in that order.

2 · Tabula recta

The table

Row one is the EQ order. Each following row is the previous one shifted left by one. To encipher, find the key letter's row and the plaintext letter's column. The highlighted cells are the lookups for the current intent.

4 · Witches' Wheel

The sigil

The 26 letters sit at equal spacing around the circle in EQ order, A at the top, running clockwise. The sigil is one continuous path visiting each letter of the final string in sequence.

  • A small circle marks the first letter.
  • An arrowhead marks the last letter, pointing along the final stroke.
  • Letters of the string are lit on the rim; the rest stay dim.
